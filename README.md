# Aura Weather - Native Android Application

A complete, production-ready Native Android Weather Application using Kotlin and Jetpack Compose (Material 3).

## Key Features
- **Clean Architecture & MVVM**: Unidirectional Data Flow with `StateFlow<WeatherUiState>` and Coroutines.
- **Retrofit2 & Kotlinx Serialization**: Robust OpenWeatherMap API integration with `Resource<T>` state mapping.
- **Dark Glassmorphic UI**: Custom deep midnight sapphire theme (#0A0E1A, #0F131F) with electric cyan accents.
- **Atmospheric Live Radar**: Dark map tile engine with pulsating Doppler beacon and time scrubber.
- **Monitored Realms**: Saved cities with Thermal Horizon Spectrum comparative visual bars.

## Open in Android Studio
1. Open Android Studio (Ladybug 2024.2+ or Hedgehog+).
2. Select **File > Open** and select the `AuraWeather` folder.
3. Allow Gradle to sync.
4. Run on an Android Emulator or physical device (API 26+).
